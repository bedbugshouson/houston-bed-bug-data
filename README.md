# Houston infestation code citations by ZIP code (2014 to 2026)

A small open dataset summarizing City of Houston code-enforcement citations for insect and ectoparasite infestations (Houston Code of Ordinances Sec. 10-344(a)), grouped by ZIP code.

| ZIP | Area | Citations |
|---|---|---|
| 77035 | Westbury / Fondren | 35 |
| 77074 | Sharpstown | 32 |
| 77076 | Independence Heights | 20 |
| 77009 | Near Northside / Woodland Heights | 10 |
| 77022 | Independence Heights (North) | 10 |
| 77016 | Trinity Gardens | 8 |

Data file: [docs/data.csv](docs/data.csv)

**Limits:** these are code violations, not confirmed bed bug cases, and they only reflect problems severe or visible enough to be cited.

**Full write-up** with income comparisons and context: [Houston Bed Bug Report](https://houstonbedbugs.com/houston-bed-bug-report/).

**Sources:** City of Houston Department of Neighborhoods open data (Building Code Enforcement Violations); U.S. Census Bureau ACS 2024 5-year estimates.

Maintained by [Houston Bed Bugs](https://houstonbedbugs.com/).
